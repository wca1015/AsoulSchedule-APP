### 模块2：🖼️ 枝江周程表识别（核心亮点）

这是本APP区别于通用工具的关键功能：

#### 识别流程
```
┌──────────────────────────────────────────────────┐
│              周程表图片识别 Pipeline               │
├──────────────────────────────────────────────────┤
│                                                  │
│  ① 获取图片                                      │
│     ├─ 自动：定时抓取枝江娱乐B站动态中的图片        │
│     └─ 手动：用户截图/相册导入/粘贴链接             │
│                                                  │
│  ② 图片预处理                                     │
│     ├─ 裁剪/矫正（透视变换、去水印区域）            │
│     ├─ 增强对比度、锐化                            │
│     └─ 分区切割（按行/按列分割为单元格）            │
│                                                  │
│  ③ OCR 文字识别                                   │
│     ├─ 方案A：云端 API（百度/腾讯/阿里 OCR）       │
│     ├─ 方案B：端侧模型（MLKit / PaddleOCR Lite）  │
│     └─ 输出：结构化文本块 + 坐标位置               │
│                                                  │
│  ④ 语义解析引擎                                   │
│     ├─ 日期提取：周一~周日 / MM.DD 格式            │
│     ├─ 时间提取：HH:MM 格式                       │
│     ├─ 成员匹配：与内置成员库模糊匹配              │
│     ├─ 直播标题提取                                │
│     └─ 输出：List<LiveSchedule>                   │
│                                                  │
│  ⑤ 用户确认 & 编辑                                │
│     ├─ 预览识别结果（可修正错误）                   │
│     ├─ 勾选要添加的场次                            │
│     └─ 一键写入日历                               │
│                                                  │
└──────────────────────────────────────────────────┘
```

#### 语义解析关键规则
```kotlin
// 伪代码：周程表解析引擎
data class LiveSchedule(
val date: LocalDate,
val time: LocalTime,
val memberName: String,
val memberId: String?,      // 匹配到成员库则填充
val title: String,
val isGroupLive: Boolean,   // 团播标记
val confidence: Float       // 识别置信度
)

fun parseWeeklySchedule(ocrBlocks: List<TextBlock>): List<LiveSchedule> {
// 1. 检测表格结构（行列对齐关系）
val table = detectTableStructure(ocrBlocks)

// 2. 逐行解析
return table.rows.mapNotNull { row ->
val date = parseDate(row[0])          // "周一 8/18" → 2026-08-18
val time = parseTime(row[1])          // "20:00" → 20:00
val member = matchMember(row[2])      // "向晚" → Member.AVA
val title = row[3].text               // "游戏直播"

if (date != null && time != null) {
LiveSchedule(date, time, member?.name ?: row[2].text,
member?.uid, title,
isGroupLive = row[2].text.contains("团"),
confidence = minOf(date.conf, time.conf, member?.conf ?: 0.8f))
} else null
}
}
```

#### 识别容错设计
| 问题场景 | 解决方案 |
|:---|:---|
| 成员昵称变体（"晚晚""Ava""向晚Ava"） | 建立别名映射表，支持模糊匹配 |
| 日期格式不统一（"8.18"/"8月18日"/"周一"） | 多格式正则 + 基于当前周的相对日期推算 |
| 图片模糊/倾斜 | 端侧预处理 + 低置信度时提示用户手动修正 |
| 临时加场/改期不在周程表中 | 保留手动添加入口作为补充 |
| 周程表样式变更 | 解析规则云端下发，支持热更新模板 |

### OCR 方案对比与推荐

| 方案 | 准确率 | 成本 | 隐私 | 离线 | 推荐场景 |
|:---|:---|:---|:---|:---|:---|
| **Google MLKit** | ⭐⭐⭐⭐ | 免费 | ✅ 端侧 | ✅ | **首选MVP方案** |
| PaddleOCR Lite | ⭐⭐⭐⭐⭐ | 免费 | ✅ 端侧 | ✅ | 中文表格识别更强 |
| 百度OCR（表格识别） | ⭐⭐⭐⭐⭐ | 付费 | ❌ 云端 | ❌ | 高精度兜底 |
| GPT-4o / Qwen-VL | ⭐⭐⭐⭐⭐ | 付费 | ❌ 云端 | ❌ | 复杂排版兜底 |

> ✅ **推荐策略**：**MLKit/PaddleOCR 端侧为主 + 多模态大模型云端兜底**
> - 端侧识别置信度 ≥ 0.85 → 直接采用
> - 置信度 < 0.85 → 自动上传云端用 Qwen-VL / GPT-4o 二次识别
> - 用户也可手动触发「AI精准识别」

## 五、UI 风格建议

考虑到Asoul粉丝群体特征：

- **主题色**：Asoul应援色系（粉/蓝/紫渐变）+ 深色模式

- **Widget小组件**：桌面显示今日/明日直播，成员头像+时间

## 七、风险与合规

| 风险 | 应对 |
|:---|:---|
| 枝江娱乐周程表样式频繁变化 | 解析模板云端配置化；社区反馈机制快速迭代 |
| OCR识别率不稳定 | 必须保留手动编辑入口；置信度可视化让用户知情 |
| B站接口/枝江动态抓取被限制 | 支持手动截图导入作为保底方案 |
| 粉丝社区对非官方工具的态度 | 明确标注「非官方」；开源透明；尊重版权不存储原图 |
| 成员变动（毕业/新增） | 云端配置热更新 + APP内反馈入口 |
